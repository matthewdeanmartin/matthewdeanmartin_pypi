# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- Skip trace support

## [0.3.0] - 2026-05-16

### Changed

- CLI ergonomics improvements

### Fixed

- Live web server now validates correctly
- Live web server can find installed packages with profile data

## [0.2.0] - 2026-05-16

### Added

- Key management
- Better GUI layout and more commands

### Fixed

- Doctor now focuses on pypi-profile things rather than package installation issues
- Live web server validation
- Live web server can find installed packages with profile data

## [0.1.0] - 2026-05-16

### Added

- Initial release
- Full rewrite with complete feature set
- Minisign support
- JSON-resume integration
- GitHub Actions workflows with security hardening
- Static site publication
- Public key ingestion
- Keyring support for easier signing
- Live and local verification modes
- Interactive GUI for profile signing
