# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Python 3.14 and 3.15 support.
- Skip trace support

### Changed

- Requires Python 3.11 or newer; Python 3.10 is no longer supported.

## [0.1.0] - 2026-05-16

### Added

- Profile discovery and verification
- Web-based key verification interface
- Key management through keyring
- Support for minisign signatures
- JSON Resume format support
- Public key ingestion and caching
- Website verification with live and "sort of live" modes
- CLI tools including key management
- Profile finding capabilities
- Tiny signature support
- Table of contents support
- Installed profile packages support
