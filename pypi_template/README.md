# PyPI template demo

This folder contains a runnable demo app for the `pypi_ds` Jinja2 design system.

## Quick start

1. Change into `pypi_template`.
2. Run `make serve`.
3. Open `http://127.0.0.1:8010`.

You can override the bind address if needed:

- `make serve PORT=9000`
- `make serve HOST=0.0.0.0 PORT=9000`

## Routes

- `/` home page
- `/search` search results demo
- `/projects/pypi-ds` project detail demo
- `/health` health check
